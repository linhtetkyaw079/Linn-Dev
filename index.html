GitHub Uploader

Privacy Policy
Last updated: August 31, 2026

1. Introduction

GitHub Uploader ("the App") is an Android application that helps users upload selected files and folders to GitHub repositories. This Privacy Policy explains what information may be handled when you use the App and how that information is used.

2. Information You Provide or Authorize

Depending on the features you use, the App may handle information that you intentionally provide or authorize, including:

  • GitHub account authorization information.
  • GitHub repository and branch information.
  • Repository paths and commit messages.
  • Files and folders that you explicitly select for upload.
  • Information related to upload history stored by the App.

3. Files and Folders

The App accesses files and folders that you explicitly select using Android's file-selection functionality. Selected files are processed for the purpose of performing the upload or other actions requested by you.

4. GitHub Access

GitHub Uploader uses GitHub services to provide features such as viewing repositories, selecting branches, browsing repository contents, and uploading files.

GitHub access is performed based on the authorization you provide. The App does not claim ownership of your GitHub repositories or uploaded content.

5. How Information Is Used

  • Connecting to GitHub.
  • Displaying repositories, branches, files, and folders.
  • Uploading files and folders to the selected repository path.
  • Creating GitHub commits requested by you.
  • Displaying relevant upload history and application settings.

6. Data Storage

Some application information, such as settings or upload-history information, may be stored locally on your Android device to provide application functionality.

The App does not sell or rent your personal information to third parties.

7. Third-Party Services

The App communicates with GitHub services when you use GitHub-related features. Your use of GitHub is also subject to GitHub's own terms, policies, and privacy practices.

8. Data Security

Reasonable measures are used to protect information handled by the App. However, no method of electronic storage or transmission can guarantee absolute security.

9. Children's Privacy

The App is not specifically directed toward children and does not knowingly collect personal information from children.

10. Your Choices

You control which files, folders, repositories, and GitHub actions you select in the App. You may stop using the App at any time and revoke its GitHub authorization through your GitHub account settings.

11. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time. When changes are made, the "Last updated" date at the top of this page will be updated accordingly.

12. Contact

If you have questions or concerns about this Privacy Policy or GitHub Uploader, contact the developer through the developer's GitHub profile: github.com/linhtetkyaw079
