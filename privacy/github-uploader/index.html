GitHub Uploader

Privacy Policy
Last updated: September 2, 2026

1. Introduction

GitHub Uploader ("the App") is an Android application that allows users to upload selected files and folders to their GitHub repositories. We respect your privacy and designed the App to operate without collecting or storing your personal data on a developer-controlled online database or server.

Privacy at a glance: GitHub Uploader does not operate an online database for collecting your personal information, GitHub tokens, uploaded files, or repository data. Your GitHub authentication token is stored locally on your Android device and is used by the App to communicate with GitHub.

2. Information We Do Not Collect

The developer does not collect or store the following information on a developer-controlled online database or server:

  • GitHub access tokens.
  • GitHub passwords.
  • Personal files or folders selected for upload.
  • Repository contents.
  • Personal information for advertising or user profiling.
  • Upload history on a developer-controlled server.

3. GitHub Token Storage

GitHub authentication tokens used by the App are stored locally on the user's Android device. They are not uploaded to or stored in an online database operated by the developer.

The locally stored token is used by the App to authenticate requests to GitHub services. The App does not intentionally transmit your GitHub token to a developer-owned backend server.

GitHub access credentials are sensitive information. Users should keep their device secure and use the minimum GitHub permissions necessary for their intended use.

4. Files and Folders

The App accesses files and folders only when you explicitly select them through Android's file-selection functionality.

Selected files are processed on your device as necessary to perform the action you request. When you choose to upload content, the content is transmitted to GitHub as required to complete the requested GitHub operation.

The developer does not receive or store copies of your selected files on a developer-controlled online server.

5. GitHub Communication

GitHub Uploader communicates directly with GitHub services to provide features such as viewing repositories, selecting branches, browsing repository contents, and uploading files.

When you request a GitHub operation, information necessary for that operation is sent to GitHub. Your use of GitHub is also subject to GitHub's own terms and privacy practices.

6. Local Data Storage

The App may store limited application data locally on your Android device, such as settings, GitHub authentication information, and upload-history information, to provide its features.

This locally stored information is not uploaded to a developer-controlled online database.

7. Data Collection and Tracking

GitHub Uploader does not intentionally collect personal information for advertising, profiling, analytics, or user tracking.

The developer does not sell or rent your personal information to third parties.

8. Third-Party Services

The primary third-party service used for the App's core functionality is GitHub. GitHub receives requests and data necessary to perform the GitHub operations that you initiate.

For information about GitHub's privacy practices, please visit GitHub Privacy Statement.

9. Data Security

The App is designed to keep GitHub authentication information on the user's device rather than sending it to a developer-controlled database.

However, no electronic storage or transmission method can guarantee absolute security. Users should keep their Android device secure and should not intentionally share their GitHub access token with others.

10. Children's Privacy

The App is not specifically directed toward children and does not knowingly collect personal information from children.

11. Your Choices

You control which files, folders, repositories, and GitHub operations you select in the App. You may stop using the App at any time and may revoke or manage GitHub authorization and tokens through your GitHub account settings.

12. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time. If changes are made, the "Last updated" date on this page will be updated accordingly.
